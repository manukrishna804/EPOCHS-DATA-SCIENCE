
# Customer Churn Prediction

## Participant Name
Manu Krishna

## Project Overview
This project predicts whether a customer is likely to churn using a Machine Learning model trained on a Customer Churn dataset. The application allows users to enter customer details through a simple web interface and receive instant predictions.

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib

## Model
Random Forest Classifier

## Features
- User-friendly interface
- Real-time prediction
- Machine Learning powered
- Publicly deployable using Streamlit Community Cloud

## Future Improvements
- Better UI/UX
- Feature importance visualization
- Probability score for predictions
- Support for batch predictions
